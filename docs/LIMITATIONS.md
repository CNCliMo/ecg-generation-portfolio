# 局限性与诚实的负结果（Limitations & Negative Results）

> 本文件是作品集可信度的一部分：**不隐藏负面结果**。所有结论均可在 `results/metrics.csv` 与日志中复现。

---

## 1. 资源与预算限制

- 训练在**单卡 RTX 4060 Laptop（8GB）**上完成，且时间/供电受限的开发环境；
- v1 扩散模型：100 epochs / base 32（约 50 分钟/模型）；
  v2 模型：**40 epochs / base 48**（为赶在截止前完成而缩小预算，约 40 分钟/模型）；
- 文献（如 SSSD-ECG / SSSD-ECG-nle）使用 S4 大模型 + 数百 epochs + 多卡/长时训练，**本项目的绝对指标不可与其直接比较**；
- 结论：**同预算相对比较有效**；跨预算比较仅作参考方向。

## 2. 生成质量与节律差距

| 指标 | 本项目 | 参考 | 说明 |
|---|---|---|---|
| QT 域内 Wasserstein | 85.2 ms（v2 最佳扩散） | 机理模型 A：14.9 ms；真实=0 | 长程节律（QT/RR）仍明显欠拟合 |
| RR-CV 域内 W | 0.415 | A：0.041 | 心率变异结构没学到 |
| HR 条件 MAE | 17.1 bpm（v2） | A：0.57 bpm | 连续条件控制很弱 |
| 导联一致性残差 | 0.350 | 真实：0.0049 | 12 导联间线性关系（III/aVR/aVL/aVF 与 I/II）没被模型保持 |

## 3. 负结果（重要的学术诚实）

1. **nle 标签嵌入在小预算下未复现文献优势**：
   `c_full_v2`（nle）vs `c_mask_v2`（mask）→ mask 在 PSD（0.0099 vs 0.0117）、条件一致率（0.298 vs 0.265）、
   TSTR（0.407 vs 0.339）更好；nle 在 HR MAE（17.1 vs 21.6）、导联残差、coverage、classifier-FID 更好。
   → 混合结果，无法断言 nle 更优；需在充足预算下复验（见 `docs/PAPERS_ECG_GENERATION.md` 的改进建议）。
2. **TSTR 远低于真实数据同预算训练（control）**：0.34–0.41 vs 0.49–0.53。
   → 当前规模下合成 ECG "可用于数据增强/预训练辅助，但不足以替代真实数据"。
3. **GAN 方差大**：D 路线 3 seed 的 MMD = 0.0168±0.0221（最大 0.0422），coverage≈0（远离真实流形）。
   → GAN 训练不稳定，不适合作为主方法。
4. **条件一致率整体偏低**（0.21–0.30）：生成信号常被判为 NORM/MI/STTC，CD/HYP 尤其差
   （与分类器 HYP F1 仅 0.43、类别不平衡有关）。
5. **b_cond_v2（nle 版路线 B）下游效用未提升**（TSTR 0.133 vs B_cond 0.211）——预算限制下的负结果。

## 4. 数据与评估口径限制

- **100 Hz 采样率**：间期（尤其 QRS 宽度）分辨率约 ±10ms，delineate 精度有限；
  未使用 PTB-XL records500（500Hz）做高分辨率评估（v3 计划项）。
- **单数据集训练**：仅 PTB-XL；MIT-BIH 只作跨域参考（360Hz、单导联 MLII 映射到 Lead II）；
  无 CPSC2018/Chapman/MIMIC-IV-ECG 等跨库结果。
- **无临床验证**：无真实医师盲评/临床 Turing test（提供了盲评工具模板但未执行）；
  分类器是 5 超类研究模型，**不可用于临床诊断**。
- **测试集使用规范**：test fold 只用于最终评估；但 v2 的类别分布/阈值校准等使用了 val fold（合规）。

## 5. 架构与实现限制

- 路线 B/C 用 **1D U-Net** 替代 SSSD-ECG 的 S4 骨干（README 偏差表 #2）；S4 未实现；
- 路线 D 为 Pulse2Pulse **风格**实现，未逐层复刻（偏差表 #3）；
- 路线 A 的 12 导联投影为几何启发式（偏差表 #4）；
- 生成不支持 CFG guidance 的正式调参（v2 训练有条件 dropout，但未做 guidance scale 网格）；
- 分类器未实现自动早停（保存 val 最优 checkpoint）；v2 已加 label smoothing/EMA/阈值校准。

## 6. 工程/交付限制

- Streamlit 界面为科研演示原型：无多用户/权限、无 DICOM/FHIR 临床格式支持（v3 计划有互操作原型）；
- 仓库不包含原始数据与 checkpoint（体积/许可原因），复现需按 README 下载数据并训练；
- 示例信号（`samples/`）仅少量，供快速查看格式。

## 7. 如何解读本项目结果

- 作为**工程与评估框架**：完整、可复现、与评估同源；
- 作为**生成质量**：形态层已接近实用（MMD 0.0005），**节律/条件控制仍明显不足**；
- 作为**研究**：提供了受控预算下的系统对照与负结果，适合作为方法学讨论/后续工作的基线，
  但**不应被引用为 SOTA 或临床级结果**。

> 后续改进方向见 `docs/PAPERS_ECG_GENERATION.md` 的改进建议（充足预算、显式间期/HRV 条件、8 独立导联、S4、CFG、临床盲评、跨库等）。
